# Glossary: one name per concept

The craft books use different words for the same things. Use the **panel name** in reviews and debate items so two specialists never argue over vocabulary.

| Panel name | Also called | Meaning |
|---|---|---|
| Disruption (inciting incident) | catalyst, inciting incident, key incident (the moment it becomes personal) | The on-screen event that upsets the balance of the lead's life |
| Commitment (first turn) | break into two, plot point I, first-act turn, lock-in | The lead acts; the story can't go back |
| Midpoint shift | midpoint, false victory / false defeat, mirror moment | Reacting becomes acting; stakes rise |
| Low point | all is lost, plot point II, second-act low, dark night | The old way fails; pressure peaks |
| Crisis (the dilemma) | ultimate decision, crisis, obligatory scene | The choice between two things wanted or two things feared |
| Climax | finale, resolution of the dramatic question | The choice made on screen, with cost; proves the idea |
| Resolution | denouement, final image, closing image | What follows the climax; brief; answers the first image |
| Controlling idea | premise, theme (as a proposition), spine, what it's about | "[value] prevails / fails because [cause]" |
| Counter-idea | antithesis, the other side | The opposite proposition; must win some scenes |
| Want / need | outer goal / inner need, desire / flaw, dramatic need | The visible goal; the hidden thing underneath |
| Opposition | antagonist, forces of antagonism, obstacle, the pressure | What stands against the want: person, situation, self |
| Reason to invest | save the cat, empathy, rooting interest | Why the audience leans in, by the first turn |
| Scene turn | value charge, +/−, beat change, "because not and then" | Something is different at the end of a scene from the start |
| Escalation | progressive complications, rising action, turn turn turn | Each obstacle bigger or different in kind |
| Setup / payoff | plant / payoff, laying pipe (the bad kind), Chekhov's gun | Introduced before it matters; returns changed |
| Exposition as ammunition | pope in the pool, dramatized exposition | Facts delivered while someone wins something or the scene does something else |
| Perception shift | recognition, anagnorisis, the turn (shorts), reversal | Character and audience see differently at the same moment |
| Rug-pull | cheap twist, gotcha, "it was a dream" | A reversal only the audience experiences; the character is untouched |
| Progression | one-shift arc, A to B, change vs reveal | The lead ends somewhere new (change) or is shown for who they are (reveal) |
| Stand-alone | not a proof of concept, not a first act | Plays as a complete film on its own |
| Form | classical / minimal / anti-structure, archplot / miniplot / antiplot | What the script permits itself: closed vs open endings, active vs reactive leads, causal vs broken time |
| Subtext | text vs subtext, talking around it, on-the-nose (the failure) | What's meant under what's said |
