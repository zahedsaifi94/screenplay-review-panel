# [TITLE]: decisions file

This file is for the orchestrator. Specialists get only the "Deliberate choices" and "Standing rules" sections, copied into their briefs. Update it every time the writer decides something, and save it to the project at the end of each round.

## Current state ([DATE])
- Current script version and where it lives (project, cloud folder, screenwriting software).
- Page count and estimated running time.

## Goals
Format (short | feature), logline, length ceiling, tone, targets (festivals / competitions), production scale. Shorts: the moment the script exists to deliver. Features: form (classical / minimal / anti-structure).

## Intent (orchestrator only; share with specialists only in the Stage 2 intent round)
What the writer says the film is about, in their words or a close summary. Keep the writer's original wording in a separate file if they gave a long one.
- Controlling idea ("[value] prevails / fails because [cause]") and counter-idea.
- Intended effect, one word.

## Deliberate choices (don't flag)
Numbered. One line each: the choice, and the reason if the writer gave one.
1.

## Rejected ideas (don't re-propose)
Ideas the writer turned down, from any panel or from you. One line each.
-

## Kept as written
Lines or moments a specialist questioned and the writer chose to keep. Quote the line.
-

## Standing rules
Style rules and working rules (e.g. "no double dashes; em dash only for cut-off lines", "show changes before making them").
-

## Accepted risks
Things raised once and kept anyway (e.g. a bit that may resemble a viral video). Don't raise these again.
